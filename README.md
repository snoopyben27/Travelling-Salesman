# Travelling-Salesman



## Acknowledgements

The datasets used in this project are sourced from the **[TSPLib.Net](https://github.com/pdrozdowski/TSPLib.Net)** repository. These files are part of the **TSPLIB** benchmark library, which is the industry standard for testing Traveling Salesperson Problem (TSP) algorithms.

> **Data Source References:**
> * **Repository Source:** Drozdowski, P. *TSPLib.Net*. GitHub Repository. Available at: [https://github.com/pdrozdowski/TSPLib.Net/tree/master/TSPLIB95/tsp](https://github.com/pdrozdowski/TSPLib.Net/tree/master/TSPLIB95/tsp)
> * **Original Library:** Reinelt, G. (1991). *TSPLIB—A Library of Sample Instances for the TSP*. University of Heidelberg.
